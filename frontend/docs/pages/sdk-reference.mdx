# SDK Reference

The `invisible-wallet-sdk` is a TypeScript package providing framework adapters (React, Vue 3, Svelte, Solid.js, Angular), a framework-agnostic vanilla client, a Stellar Wallets Kit module, and utility functions for integrating Veil into web and React Native applications.

**Package:** `invisible-wallet-sdk`
**Source:** `sdk/src/`
**Entry:** `dist/index.js` / `dist/index.d.ts`

| Entry point | Import | Exports |
|---|---|---|
| Default (Core + React) | `invisible-wallet-sdk` | `useInvisibleWallet` hook, core types, error classes, and utility functions |
| Vanilla (no framework) | `invisible-wallet-sdk/vanilla` | `createInvisibleWallet` client |
| React (provider & hooks) | `invisible-wallet-sdk/react` | `VeilProvider`, `useVeilContext`, React Query hooks (`useAccount`, `useBalance`, `useSendPayment`, `useTransactionStatus`), and UI components |
| Vue 3 | `invisible-wallet-sdk/vue` | `useInvisibleWallet` composable |
| Svelte | `invisible-wallet-sdk/svelte` | `createWalletStore` readable store |
| Solid.js | `invisible-wallet-sdk/solid` | `useInvisibleWallet` reactive primitive |
| Angular | `invisible-wallet-sdk/angular` | `VeilService`, `provideVeil`, and `VeilModule` |
| Stellar Wallets Kit | `invisible-wallet-sdk/stellar-wallets-kit` | `VeilModule` and `VEIL_ID` for `@creit-tech/stellar-wallets-kit` |

All framework adapters wrap the same framework-agnostic core (`sdk/src/core.ts`), so they expose an identical set of 26 wallet actions without pulling in other frameworks.

```bash
npm install invisible-wallet-sdk @stellar/stellar-sdk
```

## Quick Start

```typescript
import { useInvisibleWallet, type TransactionSigner } from 'invisible-wallet-sdk'

const config = {
  factoryAddress: 'CAUK4MWO3TTFM6PLURSH2GPK3AB747SZGABKTCVLKCU7W2MGKHKP35GA',
  rpcUrl: 'https://soroban-testnet.stellar.org',
  networkPassphrase: 'Test SDF Network ; September 2015',
}

// Sign fee-payer transactions on your backend instead of shipping a secret key in the browser.
const feePayer: TransactionSigner = {
  publicKey: FEE_PAYER_PUBLIC_KEY,
  signTransaction: async (xdr, { networkPassphrase }) => {
    const res = await fetch('/api/sign', {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ xdr, networkPassphrase }),
    })
    if (!res.ok) throw new Error('Signing was refused')
    return (await res.json()).signedXdr
  },
}

function App() {
  const wallet = useInvisibleWallet(config)

  const handleCreate = async () => {
    // 1. Create passkey + compute wallet address
    const { publicKeyBytes } = await wallet.register('alice')

    // 2. Deploy wallet contract on-chain
    await wallet.deploy(feePayer, publicKeyBytes)
  }

  return <button onClick={handleCreate}>Create Wallet</button>
}
```

## `WalletConfig`

Configuration object passed to `useInvisibleWallet`, `createInvisibleWallet`, `createWalletStore`, or `provideVeil`.

```typescript
type WalletConfig = {
  factoryAddress: string                  // Factory contract address (C...)
  rpcUrl: string                          // Soroban RPC endpoint
  networkPassphrase: string               // e.g. Networks.TESTNET
  rpId?: string                           // WebAuthn relying party ID (default: window.location.hostname)
  origin?: string                         // WebAuthn origin (default: window.location.origin)
  storage?: StorageAdapter                // Optional custom persistence adapter
  autoReplayOnReconnect?: boolean         // Auto-replay offline outbox on browser 'online' event (default: true)
  attestationPolicy?: AttestationPolicy   // Optional WebAuthn attestation verifier run during register()
  requireAttestation?: boolean            // Abort register() if attestationPolicy is set but raw attestation is unavailable (default: false)
  sponsorSigner?: TransactionSigner       // Optional fee-bump sponsor signer
  /** @deprecated Use sponsorSigner instead. */
  sponsorSecret?: string                  // Deprecated: raw sponsor secret key
  feeBumpBaseFee?: string                 // Base fee for outer fee-bump transaction (default: BASE_FEE)
}
```

## `useInvisibleWallet(config)`

The primary React hook. Returns an `InvisibleWallet` object with state and actions.

```typescript
const wallet = useInvisibleWallet(config)
```

### State

| Property | Type | Description |
|---|---|---|
| `address` | `string \| null` | Wallet contract address, null if not registered |
| `isDeployed` | `boolean` | Whether the contract exists on-chain |
| `isPending` | `boolean` | True while any async operation is running |
| `error` | `string \| null` | Last error message |

---

## `useInvisibleWallet(config)` — Vue 3

The same wallet as a Composition API composable. Every action below is available and behaves identically; only the state differs, arriving as refs.

```vue
<script setup lang="ts">
import { useInvisibleWallet } from 'invisible-wallet-sdk/vue'

const { address, isPending, error, register, login, sendPayment } =
  useInvisibleWallet(config)
</script>

<template>
  <p v-if="address">Wallet: {{ address }}</p>
  <button v-else :disabled="isPending" @click="register('alice')">Create wallet</button>
</template>
```

### State

| Property | Type | Description |
|---|---|---|
| `state` | `Ref<WalletState>` | All four fields in one ref, for `watch(state, …)` |
| `address` | `ComputedRef<string \| null>` | Wallet contract address, null if not registered |
| `isDeployed` | `ComputedRef<boolean>` | Whether the contract exists on-chain |
| `isPending` | `ComputedRef<boolean>` | True while any async operation is running |
| `error` | `ComputedRef<string \| null>` | Last error message |

<Callout type="info">
Called from `setup()` / `<script setup>`, the composable restores a persisted session on `onMounted` and detaches on `onUnmounted` — nothing touches `localStorage` or `window` before mount, so SSR is safe. Each call creates an independent wallet, so share one instance (module scope, or `provide`/`inject`) if several components need the same state.
</Callout>

Every action re-reads the config when it runs, so a `reactive()` config lets you switch networks at runtime. The `storage` adapter is the exception — it is read once, when the wallet is created, because the offline outbox and the passkey-derived cipher belong to it.

Starters: [`examples/vue/`](https://github.com/Miracle656/veil/tree/main/examples/vue) (Vite) and [`examples/nuxt/`](https://github.com/Miracle656/veil/tree/main/examples/nuxt) (SSR).

## Actions

Every method that submits a transaction accepts a `SignerInput` (`TransactionSigner` recommended; passing a `Keypair` or secret string is deprecated so secrets stay off the browser).

### `register(username?, options?)`

Creates a new WebAuthn passkey credential and computes the deterministic wallet address.

```typescript
// Signature
register: (username?: string, options?: RegisterOptions) => Promise<RegisterResult>

// Example
const { walletAddress, publicKeyBytes } = await wallet.register('alice', {
  authenticatorAttachment: 'platform',
})
console.log(walletAddress)
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `username` | `string` (optional) | Display name for the passkey credential |
| `options` | `RegisterOptions` (optional) | Optional WebAuthn registration options (e.g. `authenticatorAttachment: 'cross-platform'` for a roaming security key) |

**Returns** `Promise<RegisterResult>`

| Field | Type | Description |
|---|---|---|
| `walletAddress` | `string` | Deterministic contract address (C...) |
| `publicKeyBytes` | `Uint8Array` | 65-byte uncompressed P-256 public key |

<Callout type="info">
The challenge used during registration is a random 32-byte nonce — it is **not** a Soroban payload. Only `signAuthEntry` uses the actual payload as the challenge.
</Callout>

---

### `deploy(signer, publicKeyBytes?)`

Deploys the wallet contract on-chain via the factory, or returns the existing address if already deployed.

```typescript
// Signature
deploy: (signer: SignerInput, publicKeyBytes?: Uint8Array) => Promise<DeployResult>

// Example
const { walletAddress, alreadyDeployed } = await wallet.deploy(feePayer, publicKeyBytes)
console.log(walletAddress, alreadyDeployed)
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `signer` | `SignerInput` | `TransactionSigner` for the fee-payer account (pays transaction fees only) |
| `publicKeyBytes` | `Uint8Array` (optional) | P-256 public key override; defaults to the key stored by `register()` |

**Returns** `Promise<DeployResult>`

| Field | Type | Description |
|---|---|---|
| `walletAddress` | `string` | Deployed contract address |
| `alreadyDeployed` | `boolean` | True if contract existed before this call |

---

### `login(options?)`

Restores an existing wallet session from storage, or discovers one on a fresh device using a credential ID or known wallet address.

```typescript
// Signature
login: (options?: LoginOptions) => Promise<{ walletAddress: string } | null>

// Example
const result = await wallet.login()
if (result) console.log('Restored:', result.walletAddress)
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `options` | `LoginOptions` (optional) | Optional `{ credentialId }` or `{ walletAddress }` for cross-device login |

**Returns** `Promise<{ walletAddress: string } | null>`

---

### `signAuthEntry(signaturePayload)`

Signs a 32-byte Soroban authorization entry payload using the stored passkey.

```typescript
// Signature
signAuthEntry: (signaturePayload: Uint8Array) => Promise<WebAuthnSignature | null>

// Example
const sig = await wallet.signAuthEntry(payload)
if (sig) console.log('Got auth signature, publicKey len:', sig.publicKey.length)
```

**Parameters**

| Name | Type | Description |
|---|---|---|
| `signaturePayload` | `Uint8Array` | 32-byte Soroban `HashIdPreimage` passed as the WebAuthn challenge |

**Returns** `Promise<WebAuthnSignature | null>` — `null` if the user cancels.

### `deriveCounterfactualAddress(publicKeyBytes)`

Derives the deterministic counterfactual wallet contract address for a 65-byte P-256 public key before deployment.


### `addSigner(signer, newPublicKeyBytes)`

Registers an additional 65-byte uncompressed P-256 public key as a valid signer on the wallet contract.

```typescript
// Signature
addSigner: (signer: SignerInput, newPublicKeyBytes: Uint8Array) => Promise<AddSignerResult>

// Example
const { signerIndex } = await wallet.addSigner(feePayer, newPublicKeyBytes)
console.log('added signer index', signerIndex)
```

---

### `registerAdditionalSigner(signer, options?)`

Creates a second WebAuthn passkey on this wallet and submits `add_signer` authorised by the primary passkey without overwriting the device's primary binding.

```typescript
// Signature
registerAdditionalSigner: (signer: SignerInput, options?: RegisterAdditionalSignerOptions) => Promise<RegisterAdditionalSignerResult>

// Example
const added = await wallet.registerAdditionalSigner(feePayer, {
  username: 'Backup security key',
  authenticatorAttachment: 'cross-platform',
})
console.log('added signer index:', added.signerIndex)
```

---

### `getAdditionalSigners()`

Returns the additional passkeys recorded on this device (excluding the primary passkey).

```typescript
// Signature
getAdditionalSigners: () => Promise<AdditionalSigner[]>

// Example
const extras = await wallet.getAdditionalSigners()
console.log('additional signers:', extras.length)
```

---

### `removeSigner(signer, signerIndex)`

Removes a registered signer from the wallet contract by index.

```typescript
// Signature
removeSigner: (signer: SignerInput, signerIndex: number) => Promise<void>

// Example
await wallet.removeSigner(feePayer, 1)
```

<Callout type="warning">
Do not remove the last signer — this will lock the contract permanently unless a guardian is configured.
</Callout>

---

### `rotateSigner(signer, username?, options?)`

Registers a new passkey and calls `rotate_signer` authorised by the current passkey, preserving the wallet address and balances.

```typescript
// Signature
rotateSigner: (signer: SignerInput, username?: string, options?: RegisterOptions) => Promise<RotateSignerResult>

// Example
const rotated = await wallet.rotateSigner(feePayer, 'alice-new-device')
console.log('rotated wallet:', rotated.walletAddress)
```

### `getSigners()`

Fetches all registered signers from the wallet contract.

```typescript
const signers = await wallet.getSigners()
```

### `setGuardian(signer, guardianAddress)`

Sets a guardian Stellar address (`G...`) for account recovery, authorised with WebAuthn.

```typescript
// Signature
setGuardian: (signer: SignerInput, guardianAddress: string) => Promise<void>

// Example
await wallet.setGuardian(feePayer, guardianAddress)
```

---

### `initiateRecovery(signer, newPublicKeyBytes)`

Starts guardian-based key recovery, opening a timelock after which the new P-256 key replaces the existing signer.

```typescript
// Signature
initiateRecovery: (signer: SignerInput, newPublicKeyBytes: Uint8Array) => Promise<InitiateRecoveryResult>

// Example
const { unlockTime } = await wallet.initiateRecovery(guardianSigner, newPublicKeyBytes)
console.log('unlock after (unix):', unlockTime)
```

**Throws:** `NoGuardianSet` if no guardian is configured on the wallet.

---

### `completeRecovery(signer)`

Completes a pending guardian recovery after the timelock has expired (permissionless — any fee-payer signer can submit it).

```typescript
// Signature
completeRecovery: (signer: SignerInput) => Promise<void>

// Example
await wallet.completeRecovery(feePayer)
```

**Throws:** `RecoveryTimelockActive` if the timelock has not expired, or `RecoveryNotPending` if no recovery is in progress.

---

### `approve(signer, spender, token, amount, expiry?)`

Sets a spending allowance for a spender on a specific token contract, authorised with WebAuthn (omitting `expiry` makes the allowance permanent).

```typescript
// Signature
approve: (signer: SignerInput, spender: string, token: string, amount: number | bigint, expiry?: number | bigint) => Promise<void>

// Example
await wallet.approve(feePayer, spenderAddress, tokenContractId, 10_000_000n)
```

---

### `getAllowance(spender, token)`

```typescript
const allowance = await wallet.getAllowance(spenderAddress, tokenContractId)
```

### `sendPayment(signer, to, amount, token?, memo?)`

Sends a payment from the wallet contract in contract units (stroops for native XLM) using a fee-payer signer.

```typescript
// Signature
sendPayment: (signer: SignerInput, to: string, amount: number | bigint, token?: string, memo?: string) => Promise<{ transactionHash: string; status: 'PENDING' | 'SUCCESS' | 'FAILED' }>

```

### `outbox`

The durable offline `TransactionOutbox` bound to the wallet's `StorageAdapter`, used to enqueue signed transactions before submission so they survive reloads.

```typescript
// Signature
outbox: TransactionOutbox

// Example
const pending = await wallet.outbox.list()
console.log('queued transactions:', pending.length)
```

---

### `replayOutbox(opts?)`

Replays queued transactions from `wallet.outbox` against the network with at-most-once hash deduplication.

```typescript
// Signature
replayOutbox: (opts?: ReplayOptions) => Promise<ReplayResult>

// Example
const summary = await wallet.replayOutbox()
console.log('confirmed:', summary.confirmed.length)
```

---

### `encryptLocal(plaintext)`

Encrypts local application data with a symmetric key derived from the passkey via WebAuthn PRF (falling back to a persisted local key if PRF is unsupported).

```typescript
// Signature
encryptLocal: (plaintext: string | Uint8Array) => Promise<string>

// Example
const ciphertext = await wallet.encryptLocal(JSON.stringify({ note: 'rent' }))
```

---

### `decryptLocal(payload)`

Decrypts a base64 ciphertext previously produced by `encryptLocal` and returns the decoded UTF-8 string.

```typescript
// Signature
decryptLocal: (payload: string) => Promise<string>

// Example
const plaintext = await wallet.decryptLocal(ciphertext)
```

---

### `encryptionMode()`

Returns whether local encryption for the active credential uses `'prf'` (passkey-bound) or `'fallback'` (local random key).

```typescript
// Signature
encryptionMode: () => Promise<'prf' | 'fallback'>

// Example
const mode = await wallet.encryptionMode()
if (mode === 'fallback') console.warn('Device does not support WebAuthn PRF')
```

---

### `getSep43Wallet()`

Returns a SEP-0043 compliant wallet interface backed by this wallet instance.

```typescript
// Signature
getSep43Wallet: () => Sep43Wallet

// Example
const sep43 = wallet.getSep43Wallet()
const { address } = await sep43.getAddress()
```

## Types

### `WebAuthnSignature`

```typescript
interface WebAuthnSignature {
  publicKey:      Uint8Array  // 65 bytes: 0x04 || x (32B) || y (32B)
  authData:       Uint8Array  // WebAuthn authenticatorData
  clientDataJSON: Uint8Array  // UTF-8 JSON containing base64url(challenge)
  signature:      Uint8Array  // 64 bytes: r (32B) || s (32B)
}
```

### Error Classes

| Class | When thrown |
|---|---|
| `RecoveryTimelockActive` | `completeRecovery()` called before timelock expires |
| `NoGuardianSet` | Recovery methods called with no guardian configured |
| `RecoveryNotPending` | `completeRecovery()` called with no active recovery |

## Utility Functions

### `computeWalletAddress(factoryId, publicKeyBytes, networkPassphrase?)`

Compute the deterministic wallet contract address from a factory address and public key.

```typescript
import { computeWalletAddress } from 'invisible-wallet-sdk'

const addr = computeWalletAddress('CAUK4MWO3TTFM6PLURSH2GPK3AB747SZGABKTCVLKCU7W2MGKHKP35GA', pubkeyBytes)
```

### `derToRawSignature(derSig: ArrayBuffer): Uint8Array`

Convert a WebAuthn DER-encoded P-256 signature to raw 64-byte `r || s` format.

```typescript
const raw = derToRawSignature(assertion.response.signature)
```

### `extractP256PublicKey(response): Promise<Uint8Array>`

Extract the 65-byte uncompressed P-256 public key from a WebAuthn attestation response.

```typescript
const pubkey = await extractP256PublicKey(credential.response)
```

### `sha256(data: Uint8Array): Promise<Uint8Array>`

SHA-256 hash using Web Crypto API.

### `computeWebAuthnMessageHash(authData, clientDataJSON): Promise<Uint8Array>`

Compute `SHA256(authData || SHA256(clientDataJSON))` — the message hash the authenticator signs.

### `parseAuthData(authData: ArrayBuffer)`

Parse the binary `authenticatorData` structure.

```typescript
const { rpIdHash, flags, signCount } = parseAuthData(authData)
```

### `parseClientDataJSON(clientDataJSON: ArrayBuffer)`

Decode `clientDataJSON` to a typed object.

```typescript
const { type, challenge, origin } = parseClientDataJSON(clientDataJSON)
```

### `bufferToHex(input): string`

Convert bytes to hex string.

### `hexToUint8Array(hex): Uint8Array`

Convert hex string to bytes.

### `base64UrlEncode(bytes): string`

Base64url encoding without padding.

### `encodeU64(num: bigint): Uint8Array`

Encode a `bigint` as 8-byte big-endian buffer for XDR `u64` fields.
